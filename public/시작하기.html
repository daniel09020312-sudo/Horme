Ὁρμή 시작하기

Ὁρμή(호르메)는 iPad · iPhone · Android에서 쓰는 나만의 홈 화면 웹 앱이에요. 움직이는 배경, 위젯, 폴더, 앱 보관함, 빠른 검색을 갖췄고, 디자인 스튜디오에서 사진·영상·아이콘·색을 바꿀 수 있어요. 기기의 진짜 홈 화면을 바꾸지는 않고, Ὁρμή를 열었을 때 그 안에서 동작해요.

Ὁρμή 열기디자인 스튜디오로고 시안 보기

01

설치하기

  1. 이 폴더(압축을 푼 HORME 폴더 안의 파일 전체)를 Netlify Drop이나 Cloudflare Pages 같은 정적 호스팅에 올려 https 주소를 받아요.
  2. iPad · iPhone: Safari로 주소를 열고 공유 → 홈 화면에 추가. (‘웹 앱으로 열기’가 보이면 켜 두세요)
  3. Android: Chrome 메뉴 ⋮ → 앱 설치(또는 홈 화면에 추가).
  4. 홈 화면의 η 아이콘으로 열면 주소창 없는 전체 화면 앱이 돼요.

이전 버전(PRISM · LAYER · 1.x)을 쓰고 있었다면: 같은 주소에 이 버전을 덮어서 올리면 처음 열 때 앱 배치·아이콘 이미지·배경 사진·영상·위젯이 자동으로 옮겨져요. 주소가 바뀌면 브라우저가 예전 데이터를 볼 수 없으니, 예전 버전에서 ‘설정 내보내기’한 JSON을 새 버전의 설정 → 백업 불러오기로 넣으세요.

업데이트를 올리면 앱에 “새 버전이 준비됐어요 · 업데이트” 알림이 떠요. 누르면 바로 새 버전으로 바뀌어요.

02

홈 화면 다루기

넘기기

손가락을 따라 페이지가 움직이고, 놓으면 손가락 속도 그대로 미끄러지다 살짝 튕기며 멈춰요. 움직이는 페이지를 다시 잡을 수도 있어요. 마지막 페이지는 앱 보관함. 키보드는 ← →, 트랙패드는 두 손가락 가로 스와이프.

길게 누르기

아이콘·위젯·폴더를 길게 누르면 빠른 메뉴(앱/웹으로 열기, 편집, Dock, 페이지 이동, 삭제)가 떠요. 마우스는 오른쪽 클릭.

편집 모드

상단 연필 버튼, 또는 길게 누른 채로 움직이면 아이콘이 흔들려요. 끌어서 순서를 바꾸고, 화면 가장자리에 잠깐 대고 있으면 옆 페이지로 넘어가요(가장자리가 빛으로 차오르면 넘어가요. 마지막 페이지 뒤로 끌면 새 페이지가 생겨요). 빈 곳을 탭하거나 완료로 끝내요.

여러 개 한꺼번에

아이콘을 끄는 동안 다른 손가락으로 다른 아이콘을 톡톡 누르면 묶음에 더해져요(숫자가 늘어나요). 놓은 자리에 순서대로 놓여요. 또는 편집 모드의 선택으로 여러 개를 고른 뒤 옮기기(쪽·새 페이지·Dock) · 폴더로 묶기 · 홈에서 빼기 · 삭제를 한 번에 할 수 있어요. 고른 것 중 하나를 끌면 모두 함께 따라와요.

빠르게 지우기

아이콘을 끌면 화면 위에 홈에서 빼기와 삭제가 나타나요. 거기에 놓으면 바로 처리되고(묶음이면 전부), 알림의 되돌리기로 취소할 수 있어요. 편집 모드의 −는 홈 화면에서만 빼요. 앱 보관함의 전체 목록에서는 줄을 왼쪽으로 밀면 삭제가 나오고, 끝까지 밀면 바로 지워져요(마우스는 줄에 올리면 휴지통, 키보드는 Delete). 선택으로 여러 개를 골라 한 번에 지울 수도 있어요.

빈 페이지

편집 모드에서 빈 페이지에는 이 페이지 지우기 버튼이 보여요. 편집을 마치면 빈 페이지는 저절로 정리돼요(되돌리기 가능). 앱이 있는 페이지는 페이지 버튼에서 지울 수 있어요.

카테고리 화면

앱 보관함에서 카테고리 이름을 누르면 카테고리마다 다른 방식으로 앱을 골라요. 게임은 무작위 선으로 잘린 조각, 엔터테인먼트는 다이얼, 소셜은 궤도, 크리에이티브는 물감 방울, 공부는 카드, 생산성은 키보드, 유틸리티는 스위치, 생활은 지도. 위쪽에서 다른 방식으로 바꾸면 카테고리마다 기억해요.

폴더

편집 모드에서 앱을 다른 앱 한가운데에 잠깐 올려 두면 폴더가 돼요. 폴더를 열어 이름을 바꾸고, 앱을 바깥으로 끌어내면 꺼낼 수 있어요.

Dock

아이콘을 아래 Dock으로 끌거나 메뉴에서 ‘Dock에 넣기’. 최대 10개, 화면이 좁으면 아이콘 크기가 자동으로 맞춰져요.

빠른 검색

돋보기 버튼이나 ⌘K · /. 앱 이름·별칭·초성(ㅇㅌㅂ → YouTube)으로 찾고, 12*(3+4) 같은 계산, ‘위젯 추가’ 같은 명령, 웹 검색까지 돼요.

실수했다면 편집 모드의 되돌리기 버튼이나 ⌘Z, 또는 알림의 되돌리기를 누르세요. 최근 40번까지 되돌릴 수 있어요.

‘홈 화면에서 빼기’는 아이콘만 치우는 거라 앱 보관함에 남아요. ‘삭제’는 Ὁρμή에서 바로가기를 지우는 것이고, 기기에 설치된 실제 앱은 지워지지 않아요.

03

앱 연결하기

단축어로 아무 앱이나 열기

  1. 단축어 앱 → + → 동작 추가에서 ‘앱 열기’ → 열 앱 선택.
  2. 단축어 이름을 정해요. 예: 카메라 열기
  3. Ὁρμή에서 그 아이콘을 누르면 나오는 연결하기 화면(또는 앱 편집 → ‘단축어로 연결…’)에 같은 이름을 넣어요.

Ὁρμή는 애플이 공개한 형식 shortcuts://run-shortcut?name=…을 써요. 실행할 때 단축어 앱이 잠깐 보였다가 앱이 열려요.

처음 열면 이 앱들로 시작해요: Dock에 Chrome · YouTube · Ὁρμή 설정, 첫 화면에 공부방 플래너 · 카카오톡 · ChatGPT · Claude와 폴더 4개(교육: Classroom · 리로스쿨 · Notability / 생산성: Google Docs · Drive · Slides · Polaris Viewer · vFlat Scan · App Store / 음악: YouTube Music · SoundCloud · Bose / 사진: 사진 · 카메라), 보관함에 Google Sheets · VPN. 설정 → 모두 초기화를 하면 이 구성으로 돌아가요. 애플 앱을 쓰던 홈 화면은 설정 → 애플 앱을 구글 앱으로 바꾸기로 자리 그대로 바꿀 수 있어요. 목록에 없는 앱은 앱 보관함 → 앱 추가에서 고르거나 직접 만들기로 추가하고, 디자인 팩에 아이콘을 넣어 한꺼번에 더할 수도 있어요. 아이콘 위의 노란 점은 “아직 연결 주소가 없음” 표시예요.

05

디자인 스튜디오

상단 디자인 버튼. 오른쪽(휴대폰은 ‘미리보기’ 버튼)에 실제 Ὁρμή 화면이 그대로 보이고, 바꾸는 즉시 반영돼요. iPad 가로·세로·휴대폰 크기를 골라 볼 수 있어요.

  • 배경: 기본 움직임 / 사진(가로·세로 따로) / 영상(MP4 권장, 300MB 이하) / 움직이는 이미지(GIF·APNG·WebP). 어둡게·흐리게, 입자 효과 겹치기.
  • 한 번에 적용: 디자인 팩(아래) — 배경·아이콘·색을 파일 하나 또는 AI 답 하나로.
  • 아이콘: 앱마다 이미지 넣기, 기본 기호 바꾸기, 파일 이름으로 여러 개 한 번에(youtube.png, 유튜브.png 모두 인식, 없는 앱 이름이면 그 앱을 새로 더해요), 크기·모서리·이름 표시.
  • 테마: 7가지 분위기, 포인트 색 2개, 시계 글꼴(얇게·세리프·모노·둥글게), 위젯·Dock 모양, 간격, 시계 아래 문구.
  • 위젯: 페이지별 위젯 목록, 추가·편집·크기·삭제.
  • AI 프롬프트: 아이콘·아이콘 세트·위젯·가로/세로 배경·배경 영상용 설명문을 영어/한국어로 만들어 복사.
  • 백업: 전체 백업 · 불러오기 · 초기화 · 저장 공간 확인.

app-icon-pack 폴더에는 같은 스타일의 앱 아이콘 72개(PNG·SVG)가 들어 있어요. 단축어 앱의 ‘홈 화면에 추가’에서 아이콘으로 쓰면 iPad의 진짜 홈 화면도 같은 분위기로 맞출 수 있어요.

06

디자인 팩 — 한 번에 적용

배경·앱 아이콘·테마 색을 한 번에 바꿔요. 설정의 디자인 팩 적용, 또는 디자인 스튜디오 ① 한 번에 적용에서 써요. 적용 전에 무엇이 바뀌는지 보여 주고, 적용한 뒤에도 되돌리기로 취소할 수 있어요.

파일로

zip 하나, 또는 파일 여러 개를 한꺼번에 고르면 이름을 보고 알아서 넣어요.

색·글꼴·문구pack.json (아래 형식)

아이콘이 앱을 정해요. 홈 화면에 없는 앱의 아이콘을 넣으면 그 앱이 더해지고(알려진 앱이면 링크까지 자동), 처음 보는 이름이면 그 이름의 바로가기를 만들어요. 아이콘이 4개 이상이면 “이 아이콘들로 홈 화면 앱 구성하기”가 켜진 채로 열려서, 홈 화면과 Dock이 팩에 든 앱으로 바뀌어요(위젯은 그대로).

AI에게 맡기기

  1. 스튜디오 ① 한 번에 적용에서 원하는 분위기를 적고 프롬프트 복사.
  2. Claude · ChatGPT · Gemini 같은 AI 채팅에 붙여 넣기. 프롬프트에 지금 홈 화면의 앱 목록과 형식이 다 들어 있어요.
  3. 글로 받기를 골랐다면 AI의 답을 통째로 복사해 AI 답 붙여넣기에 넣고 적용. 아이콘·배경이 SVG 코드로 들어 있어서 파일이 필요 없어요. 이미지 zip을 골랐다면 AI가 준 zip을 파일로 한 번에에 넣어요.

07

움직임과 효과

설정 → 움직임 · 효과. 모든 효과는 손가락이 닿아 있는 동안이나 멈추기까지의 짧은 순간에만 계산해서, 가만히 두면 배터리를 쓰지 않아요.

  • 페이지 넘김: 젤리(아이콘이 열마다 살짝 늦게 따라오며 출렁) · 기본 · 깊이(뒤로 물러나며 회전) · 큐브(정육면체처럼 회전).
  • 쫀득함: 담백하게 · 보통 · 쫀득하게 — 페이지·아이콘·창·폴더가 멈출 때 튕기는 정도. 모두 같은 물리 계산(스프링)으로 움직여요.
  • 손끝 반응 배경: 누른 곳에서 빛의 물결이 퍼지고 입자가 밀려나요.
  • 아이콘 기울기 · 빛 반사: 누르는 쪽으로 아이콘이 눌려 기울고 빛이 손끝을 따라와요. 트랙패드 커서를 올리면 살짝 떠올라 커서 쪽으로 기울어요. 앱을 열 때는 아이콘이 톡 튀며 빛이 번져요.
  • 배경 깊이감: 페이지를 넘기면 배경이 아이콘보다 느리게 따라와 깊이가 느껴져요.
  • Dock 확대: Dock 위를 손가락으로 쓸거나 커서를 올리면 아이콘이 커져요.
  • 편집 모드에서 끄는 아이콘은 손가락보다 살짝 늦게, 움직이는 방향으로 기울며 따라와요.

손을 뗀 뒤 페이지가 미끄러져 멈추는 움직임은 미리 계산해서 브라우저의 합성 단계(GPU)가 그려요. 그래서 다른 일이 몰려도 끊기지 않아요.

기기의 ‘동작 줄이기’를 켜면 튕김과 효과가 꺼지고 차분하게 움직여요.

08

백업과 기기 옮기기

  • 전체 백업(zip): 앱 배치·위젯·디자인과 사진·아이콘·영상까지 파일 하나. iPad에서는 공유 시트가 열리면 ‘파일에 저장’을 고르세요.
  • 설정만(JSON): 사진·영상 없이 가벼운 파일.
  • 불러오기: 위 두 가지와 예전 버전의 ‘설정 내보내기’ JSON, ‘디자인 파일’ JSON 모두 돼요. 불러오기 직후 ‘되돌리기’로 취소할 수 있어요.

모든 데이터는 이 기기·이 주소에만 저장돼요(계정·서버 없음). 브라우저 데이터를 지우거나 주소를 바꾸기 전에 전체 백업을 해 두세요.

배터리 아끼기

설정 → 배터리에서 정해요. 기본값(자동)만으로도 2.0보다 훨씬 적게 써요.

전원 모드배경그 밖에
절전멈춘 한 장면흐림 효과 끔, 초 단위 표시·시계 초침·사진 자동 넘김 쉼, 배경 영상 일시정지, 날씨는 90분마다
기본1초에 20장(만지는 동안은 화면 주사율 그대로), 낮은 해상도위젯·Dock 뒤에는 그리지 않아서 흐림 효과를 다시 계산할 필요가 없어요
부드럽게화면 주사율 그대로, 선명하게, 색 번짐도 움직임콜론 깜빡임 등 모든 효과. 전기를 가장 많이 써요

자동은 이렇게 골라요: 배터리 20% 이하(충전 중 아님)·기기 저전력 모드·데이터 절약 모드 → 절전, 충전 중 → 부드럽게, 그 밖에는 기본. iPad·iPhone은 배터리 잔량을 웹 앱에 알려 주지 않아서, 저전력 모드는 화면 갱신 속도가 30번으로 줄어드는 것으로 알아채요. 설정의 ‘지금:’ 줄에 어떤 모드가 왜 골라졌는지 나와요.

  • 완전한 검정 배경: OLED 화면(대부분의 iPhone, 최신 iPad Pro)은 검은 부분의 픽셀이 꺼져서 전기를 덜 써요. LCD iPad에서는 차이가 거의 없어요.
  • 설정·폴더·빠른 검색이 열려 있거나 스탠바이 시계를 켜 둔 동안에는 뒤 배경을 그리지 않아요. 다른 앱을 쓰는 동안에는 아무것도 움직이지 않아요.
  • 사진 배경은 움직이지 않으니 원래 거의 쓰지 않아요. 배경 영상은 가장 많이 쓰니, 오래 켜 둘 때는 사진이나 기본 배경을 권해요.

10

문제 해결

배경 영상이 안 나와요

MP4(H.264)로 바꿔 보세요. 아이폰으로 찍은 HEVC(MOV)나 AVI·MKV는 기기에 따라 재생되지 않아요. 저전력 모드에서는 자동 재생이 멈출 수 있는데, 화면을 한 번 탭하면 다시 재생돼요.

앱이 아니라 웹이 열려요

그 앱이 설치돼 있지 않거나 앱 주소를 지원하지 않는 거예요. 앱 편집에서 여는 방식을 ‘앱만’으로 바꾸거나 단축어로 연결하세요.

“주소가 유효하지 않음” 알림이 떠요

앱이 설치되지 않은 상태에서 앱 주소를 열면 Safari가 띄우는 알림이에요. 잠시 뒤 웹으로 열려요. 거슬리면 여는 방식을 ‘웹만’으로 바꾸세요.

홈 화면 아이콘이 예전 것이에요

iOS는 설치할 때의 아이콘을 기억해요. 홈 화면의 Ὁρμή 아이콘을 지우고 다시 ‘홈 화면에 추가’ 하세요.

앱을 나갔다 오니 화면이 한쪽에 작게 보여요

iPadOS가 홈 화면 웹 앱을 다시 열 때 화면 크기를 잘못 알려 주는 경우가 있어요. 2.2부터는 돌아오는 순간 Ὁρμή가 스스로 크기를 다시 맞춰요. 그래도 그대로라면 iPad를 한 번 돌렸다가 되돌리면 바로 맞춰져요.

날씨가 안 나와요

인터넷 연결이 필요해요. 위치 권한을 거부했다면 위젯 편집에서 도시를 검색해 주세요.

배터리가 걱정돼요

설정 → 배터리에서 절전을 고르면 화면에 움직이는 것이 거의 없어져요. 자세한 내용은 배터리 아끼기를 보세요. 기기의 ‘동작 줄이기’가 켜져 있으면 배경 움직임은 자동으로 멈춰요.

바뀐 점

2.3 — 여러 개 다루기 · 카테고리 화면

  • 아이콘을 끄는 중에 다른 손가락으로 아이콘을 눌러 묶음으로 옮길 수 있어요. 편집 모드의 선택으로 여러 개를 골라 옮기기·폴더로 묶기·빼기·삭제를 한 번에.
  • 끄는 동안 화면 위에 홈에서 빼기 · 삭제 칸이 나타나요. 놓기만 하면 바로 지워지고 되돌릴 수 있어요.
  • 빈 페이지는 편집 모드에서 바로 지울 수 있고, 편집을 마치면 저절로 정리돼요.
  • 앱 보관함 → 전체 목록: 줄을 왼쪽으로 밀어 삭제, 끝까지 밀면 바로 삭제, 여러 개 골라 한 번에 삭제.
  • 앱 보관함의 카테고리마다 다른 고르기 화면: 게임은 무작위 선으로 나뉜 조각을 눌러 고르고, 다이얼·궤도·물감·카드·키보드·스위치·지도 방식도 있어요.
  • ‘게임’ 카테고리와 게임 앱(Roblox · Minecraft · 브롤스타즈 · 클래시 로얄 · 원신 등)을 더했어요.
  • 기본 앱 구성을 바꿨어요: 공부방 플래너 · 리로스쿨 · 카카오톡 · ChatGPT · Claude · Google Docs/Drive/Sheets/Slides · Classroom · Notability · Polaris Viewer · vFlat Scan · YouTube · YouTube Music · SoundCloud · Bose · 사진 · 카메라 · App Store · VPN · Chrome · Ὁρμή 설정. 이미 쓰던 홈 화면은 그대로예요.
  • 페이지 넘김: 손을 뗀 뒤의 움직임을 GPU가 그려 더 끊김 없이 미끄러져요. 넘기는 동안 배경을 다시 그리지 않아요.
  • 아이콘 끌기: iPad에서 끌기가 중간에 멈추던 문제, 가장자리 페이지 넘김이 잘 안 되던 문제(넓어진 가장자리 칸과 차오르는 표시), 넘어간 페이지에서 자리가 엉뚱하게 잡히던 문제를 고쳤어요.

2.2 — 조작감 · 디자인 팩

  • 페이지·드래그·창이 모두 스프링 물리로 움직여요. 손가락 속도가 그대로 이어지고, 움직이는 페이지를 다시 잡을 수 있어요. 손가락이 닿아 있는 동안 배경은 화면 주사율 그대로 그려요.
  • 새 효과: 젤리·깊이·큐브 페이지 넘김, 아이콘 기울기와 빛 반사, 트랙패드 호버, 앱 열기 효과, 손끝 물결, 배경 깊이감, Dock 확대.
  • 디자인 팩: 배경·아이콘·색을 파일 하나나 AI 답 하나로 한 번에. 아이콘으로 홈 화면 앱 구성까지.
  • 기본 앱을 구글 앱으로 바꿨어요. 기존 홈 화면은 설정에서 한 번에 바꿀 수 있어요.
  • iPadOS에서 앱을 나갔다 돌아오면 화면이 한쪽에 작게 그려지던 문제를 고쳤어요.
  • ‘배경 움직임’ 위젯의 막대가 다시 부드럽게 움직여요. 기본 모드 배경은 1초 20장(손대는 동안은 최고 속도). 가만히 둘 때 CPU는 2.0의 약 4분의 1이에요.

2.1 — 배터리

  • 전원 모드(자동·절전·기본·부드럽게)와 완전한 검정 배경을 추가했어요.
  • 기본 배경을 1초 30장 → 12장, 고해상도 → 기기 해상도 1배로 그리고, 색 번짐은 한 번만 그려요. 위젯·Dock 뒤는 비워서 흐림 효과를 매번 다시 계산하지 않아요.
  • ‘배경 움직임’ 위젯의 막대가 따로 1초 60번 움직이던 것을 배경과 같은 장면에 맞춰 그려요.
  • 시계는 1초마다 깨어나던 것을 필요할 때만(초 표시·초침·타이머가 있을 때) 1초마다, 그 밖에는 1분에 한 번 깨어나요. 사진 위젯은 넘길 때만 깨어나요.
  • 테스트 브라우저(iPad 가로 크기, 기본 배경)에서 잰 CPU 사용량: 2.0 약 130% → 2.1 기본 약 20%, 절전 약 0%.
